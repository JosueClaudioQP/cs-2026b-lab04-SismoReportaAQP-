Este archivo es una guía para revisión real; no es evidencia de aprobación.
Cada integrante debe abrir su PR y otro integrante responder estas preguntas:

1. ¿Qué olor concreto elimina este patrón y en qué método estaba?
2. ¿Qué prueba demuestra el contrato y la extensibilidad?
3. ¿Es el patrón más simple para resolverlo? ¿Qué se rechazó?
4. ¿Cambió algún resultado, excepción, evento o número de reintentos?
5. ¿Las métricas corresponden al código incluido en el PR?
